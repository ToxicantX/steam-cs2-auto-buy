# Steam CS2 Auto Buy

面向 `CS2 / Steam 社区市场` 的桌面自动化工具发布仓库。

这个仓库用于：

- 展示项目简介
- 提供安装包下载入口
- 跟踪版本发布记录

源码开发仓库：

- `ToxicantX/steam-auto-bot`

## 当前能力

- Steam 网页会话登录与状态复用
- 市场搜索与结果筛选
- 条件自动购买
  - 按最高价格限制
  - 按磨损 Float 限制
  - 支持多任务顺序执行
- 任务历史记录与模板复用
- 炼金记录读取与本地缓存
- 炼金记录价格同步与收益估算
- 可切换显示浏览器 / 静默运行

## 最近更新

- 优化网页登录状态检测，Steam 瞬时网络波动时不再轻易把当前会话误判为已退出
- 扫码登录成功后会更快展示账号头像、钱包余额与当前账号信息
- 加强市场页访问重试策略，降低临时网络错误对使用流程的影响
- 桌面端名称已更新为“CS小购”，Windows 安装包图标同步更新

## 使用说明

1. 启动程序
2. 通过 Steam 网页完成登录
3. 搜索目标饰品并填写购买条件
4. 加入任务队列并执行
5. 按需要查看任务历史、库存价格或炼金记录

## 系统要求

- Windows
- Node.js 20 仅在源码开发/本地构建时需要

## 风险提示

- 本项目涉及 Steam 市场自动化操作，请自行评估账号与平台规则风险
- 建议先使用低价值饰品和小批量任务验证流程
- 如 Steam 页面结构或接口行为变化，部分功能可能需要调整后才能继续使用
